# Switch Time — 集中を、切り替える。

iPhone・iPadでホーム画面に追加できる、切り替え式ストップウォッチです。

## 最初の一度だけ：公開する

1. [Settings → Pages](https://github.com/tarryaa/time/settings/pages) を開きます。
2. **Build and deployment → Source** を **Deploy from a branch** にします。
3. **Branch** を **main**、フォルダを **/ (root)** にして **Save** を押します。
4. 数分後、 **https://tarryaa.github.io/time/** にアプリが公開されます。

このリポジトリのルートにアプリ本体を配置済みです。インストールやビルドは不要です。以後はファイルを更新するとGitHub Pagesが自動で反映します。

## ホーム画面に追加

**iPhone / iPad:** [公開URL](https://tarryaa.github.io/time/) をSafariで開く → 共有 → **ホーム画面に追加** → 追加。

**Android:** Chromeで公開URLを開く → メニュー ⋮ → **ホーム画面に追加 / アプリをインストール**。

GitHubのコード画面ではなく、GitHub Pagesの公開URLを開いてください。

## タイマー

- カードをタップして開始。別のカードをタップすると、前を止めて次を開始します。
- 最大12個。名前と色を編集でき、組み合わせをプリセットとして保存できます。
- 個別時間と合計時間が自動連動。「一時停止」で全体を止め、任意のカードから再開できます。
- リセットすると全タイマーと合計が0になり、計測が停止します。
- 名前・色・組み合わせをプリセットとして端末に保存できます。
- iPhone・iPad・PC対応。オフラインで起動でき、対応端末では画面の保持も可能です。

### アプリ終了・電源オフの間の計測

動作中のタイマーは、保存した開始時刻と再び開いた時刻の差から経過時間を復元します。アプリを完全終了した場合や端末の電源がオフだった場合も、その間の時間を加算します。休憩したい場合は、閉じる前に明示的に一時停止してください。

電源オフ中にプログラムが実行されるわけではありませんが、再び開くと、時間の表示は継続していた場合と同じになります。端末の時計を手動変更すると計測に影響する場合があります。

## リズム通知（等間隔の音）

タイマー画面にある **リズム通知** の専用スイッチをオンにした間だけ通知します。ストップウォッチの一時停止とは独立して動きます。

歯車ボタンから以下を設定できます。

- **間隔:** 秒・分・時間で自由入力。1秒〜24時間。
- **音量:** 0〜100%。端末本体の音量も反映されます。
- **音:** トン / やわらかなベル / 小さなクリック / ピッ / しずく。
- **自分の音:** 音声ファイル（MP3・WAVなど）も使用可能。10MB以下、先頭3秒を使います。対応形式はブラウザに依存します。
- **試聴:** 選んだ音と音量で確認できます。

初期状態はオフです。バイブ機能はありません。

## 経過時間の読み上げ（短い録音音声）

「5分」「10分」「15分」「1時間5分」などを、それぞれ普通の日本語読み上げで事前に録音した音声ファイルから再生します。声の高さや速さを変えず、単位ごとの古い声をつなぐ方式も使いません。

**初期設定は5分間隔**。5・10・15・30分・1時間から選べます。従来の秒単位の設定は、新方式への移行時に5分間隔へ切り替えます。計測済みの時間は残ります。

- 「開始」から読み上げ用の時間を独立して計測します。
- 5分間隔なら **5分 → 10分 → 15分 → … → 1時間5分**。
- 「ストップ」で、いま鳴っている声と読み上げ用の時間を止めます。「再開」で続きから計測します。
- ↺ は読み上げの時間だけを0に戻します。
- 音量を調整できます。設定の **「5分」を試聴** と **「1時間5分」を試聴** で声を確認できます。

### 音楽・YouTubeと一緒に使う

リズム通知は、最初の版と同じWeb Audioの短い効果音再生に戻しました。長時間のMP3再生、バックグラウンド用Worker、AudioSessionのモード変更、ロック画面のメディア操作は使いません。

読み上げも、短い録音音声を同じAudioContextで単発再生します。ブラウザのリアルタイム音声合成や再生速度による声の高さの変更は行いません。音声素材は24kHz・64kbpsです。初めの24時間は各時刻の文章をひとまとまりの音声で再生します。それ以降も録音素材から継続できます。

iPhone・iPadで他アプリの音楽・YouTubeとの同時再生は実機未検証です。ブラウザでは別の音声ソースの再生を継続したまま効果音と録音音声が鳴ることを確認しています。

### アプリを開いている間だけ音を鳴らす

**リズム通知・読み上げともに、アプリが表示されている間だけ音が鳴ります。** 閉じる・画面をロックする・他アプリに切り替えると音声を止め、未来の音声も予約しません。戻ったときに過去の通知をまとめて鳴らすことはありません。

閉じている間も、リズム通知の間隔、動作中のストップウォッチと読み上げの経過時間は開始時刻から復元します。音を鳴らすには再度タップが必要な場合があります。

### イヤホン

イヤホン検知は行わず、端末の出力先から再生します。イヤホンを外すとスピーカーから鳴る場合があります。

## 保存

時間・プリセット・通知音設定はブラウザの `localStorage`、自分の音声ファイルは `IndexedDB` に保存します。サーバーへ計測データや音声ファイルを送信しません。端末間の同期はありません。

Safariとホーム画面版などで保存領域が別になる場合があります。使い始めた後は同じ開き方で使ってください。ブラウザのデータを削除すると、保存内容も消えます。

## 開発・動作確認

```sh
node --test tests/*.test.mjs
python -m http.server 8080
```

`http://localhost:8080` を開きます。PWAにはHTTPSまたはlocalhostが必要です。フォントはオンライン時にGoogle Fontsから取得し、オフラインでは端末の標準フォントを使用します。

更新時は `sw.js` の `CACHE` 名を変更してください。新しいバージョンは、開いているアプリの画面を全て閉じた後の再起動で適用されます。

## 音声素材とライセンス

現在の短い日本語読み上げは、汎用の時間表現をgTTSで事前に音声化した録音です。再生時には生成サービスにアクセスせず、アプリから配信する音声素材を使用します。タイマー名などのユーザー入力は音声生成サービスに送信しません。

- [gTTS 2.5.4](https://github.com/pndurette/gTTS): 音声素材の生成に使用（Pythonツール、MITライセンス）。
- リポジトリに残る旧バックグラウンド再生用のlamejs・LAMEは使用しません。ライセンスは `vendor/LICENSE-LGPL.txt` と `vendor/LICENSE-lamejs.txt`。
- リポジトリに残る旧Mei音声素材のライセンスは `audio/LICENSE-Mei.txt`（CC BY 3.0）。新しい短い録音音声では使用しません。
